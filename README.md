# FluxVid — Universal Video & Audio Downloader
**Created By Shiv Yogi**

FluxVid is a high-performance, mobile-first media downloader with a sleek liquid-glass design system.

---

### Prerequisites
1. **Python 3.10+**
2. **FFmpeg installed on the server**:
   - Ubuntu/Debian: `sudo apt update && sudo apt install -y ffmpeg`
   - Termux / Android: `pkg install ffmpeg python`
   - Windows: `winget install Gyan.FFmpeg` or download from [gyan.dev](https://www.gyan.dev/ffmpeg/builds/)
   - macOS: `brew install ffmpeg`
